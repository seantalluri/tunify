      Known limitations

      Prototype scope
      • Inputs: Handles only embedded synthetic melody metadata; it does not record, upload, or analyze real audio.
      • Language: The interface, policies, prompts, and expected responses are English only.
      • Processing: Each agent request evaluates one melody case at a time; Run All sends those requests sequentially.
      • Data contract: Cases need the exact embedded CSV fields, linked record IDs, policy sections, and labeled response format used by this prototype.
      • Outputs: Produces text arrangement specifications only; it does not generate playable audio, stems, MIDI, waveform edits, or DAW exports.
